# API Data Fetcher

## Objective

Fetch data from a public API using Python Requests and allow users to search records.

## Features

- Fetch API data
- Parse JSON response
- Search users by name
- Error handling

## Technologies

- Python
- Requests Library
- JSON

## API Used

https://jsonplaceholder.typicode.com/users

## Run

```bash
python api_fetcher.py
```
